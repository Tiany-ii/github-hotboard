这是一个什么程序

一个本地运行的 GitHub 热榜看板。数据直接来自 GitHub 官方 API，不需要登录、不需要后端，断网时还能看上次的缓存。

五个榜单

  • 全站热榜：实时 Top 100，按 Star 排序，带排名升降与 Star 增量。
  • 新项目榜：按「创建时间」筛选出的近期新项目，可切近 30 天 / 90 天 / 半年，按总 Star 或日均增速排序。日均 = Star ÷ 创建天数，是唯一不需要历史数据就能算出的真实增速。
  • 分类精选：65 个值得看的项目，5 个分类，每个配一句中文点评。
  • DeepSeek 插件：6,896 个 dsh 插件，含近 30 天 npm 下载量。
  • 我的榜单：自己关注的仓库，最多 24 个。

增长曲线怎么来的

  • 每次刷新会把当前 Star 记一个采样点，存在本机。点击任意一行可看大图。
  • GitHub 不提供历史 Star 接口，所以曲线从你第一次打开本程序起累积，用得越久越完整。
  • 为了控制体积，最多保留 150 个点：越近越密，久远的会自动稀释。
  • 想马上看到曲线，把间隔调到 30 秒，几分钟后就有走势了。

刷新机制

  • 自动刷新：顶部圆环是倒计时，走完一圈自动拉取一次最新数据。间隔可在右上角切换（30 秒 ~ 15 分钟，或关闭）。
  • 手动刷新：点「刷新」或按 R 立即拉取，同时补全分类榜里未覆盖的项目。
  • 窗口切回来时会自动刷新一次（浏览器会限制后台标签页的定时器）。
  • 变化列显示相对上一次快照的 Star 增减，鼠标悬停可看对比时间。

数据来源与配额

  • 全站热榜与分类榜：api.github.com/search/repositories，按 Star 排序，实时读取。
  • DeepSeek 插件：awesome-dsh-plugin.com/plugins.json，收录 6,896 个 dsh 插件，含近 30 天 npm 下载量。
  • 未登录时搜索接口限制为 10 次 / 分钟。每次刷新只用 1 次请求，补全分类时再补 2~3 次，正常使用不会触发限制。
  • 我的榜单走的是另一套接口（60 次 / 小时），每个仓库 1 次。所以它只在打开该页或手动刷新时更新，不会跟着自动刷新一起跑。
  • 单次全站 Top 100 请求约 650 KB。若在意流量，把间隔调成 5 分钟或「手动刷新」。

快捷键

R立即刷新
/聚焦搜索
1~6切换标签
Esc清空搜索

想改榜单内容？

用文本编辑器打开本文件，搜索 const CURATED，按 ['owner/repo','分类','一句话点评'] 的格式增删即可，保存后刷新页面就生效。分类名对应 CATS 里的键。

可选：填入 GitHub Token

不填也能正常用。填入一个只读的 Personal Access Token 后，接口配额从 10 次/分钟提升到 30 次/分钟，适合把刷新间隔调到 30 秒。Token 只存在本机浏览器里，不会发往任何第三方。

翻译引擎

详情页会把英文 README 逐段翻译成中文并与原文对照。有两种引擎可选：

  • DeepSeek：需要 API Key，质量最好，能翻全文，按量计费（很便宜）。
  • 免费在线翻译：不需要 Key，走公开的 MyMemory 接口。质量尚可，但每天只有约 5,000 字符额度，够翻简介和开头十几段，翻不了长 README。

AI 总结模型

AI 总结、批量总结、每日点评都用这里的模型。翻译固定用 deepseek-flash 并关闭思考——那是机械任务，开思考只会变慢变贵。

DeepSeek API Key

翻译和 AI 总结都靠它。Key 只保存在本机，可以存多个随时切换（最多 8 个）；切换后立即生效，不需要重开程序。

备份与迁移

把「我的榜单、Star 曲线、翻译记录、界面设置」打包成一个文件。换设备、重装系统、或从网页版搬到 exe 时，导入即可恢复。备份不含 GitHub Token 和翻译 Key，新设备上需要重新填写。
